BTC 사이클 대시보드

데이터 출처 (모두 무료 공개 API)
  • 캔들(월봉·주봉): Bitstamp BTC/USD 일봉(2011-08~), UTC 기준 리샘플. 현재 봉은 미완성.
  • 온체인: Coin Metrics Community (CC BY-NC 4.0) — PriceUSD, CapMrktCurUSD, CapMVRVCur, SplyCur, HashRate. 실현 시가총액 = 시가총액 / MVRV, 실현가격 = 실현 시가총액 / 공급량, NUPL = 1 − 1/MVRV.
  • MVRV Z-Score = (시가총액 − 실현 시가총액) / 그 시점까지의 누적 시가총액 표준편차 (2010-07부터 누적, 사후 정보 없음). 온체인 패널 표시는 2011-01부터.
  • 파워로 밴드: log10(가격) ~ log10(제네시스 이후 일수) 최소제곱 적합, 잔차 분위수(5/25/50/75/95%)로 밴드 설정. 이 대시보드 자체 정의이며 2030년까지는 외삽.
  • 해시리본: 해시레이트 30D/60D SMA. Buy = 30D<60D 구간 후 30D가 60D 위로 복귀하고 가격 10D SMA > 20D SMA 인 첫 날 (Capriole 공개 정의).
  • 공포·탐욕: alternative.me. 김치프리미엄: 브라우저가 Upbit·Binance 시세와 Rates By Exchange Rate API 환율을 직접 조회해 계산 (USDT≈USD 가정, 일부 지역에서는 Binance 접속 불가).
  • 개인 연구용 비상업 프로젝트입니다. 투자 조언이 아닙니다. 매일 GitHub Actions로 다시 빌드됩니다.
  • 무료 전체 이력 소스가 없어 제외한 지표: 손실 주소 수, 공급 대비 이익/손실, HODL Waves, 현물 ETF 순유입.
